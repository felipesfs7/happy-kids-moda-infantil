# 🎈 Happy Kids Moda Infantil — E-commerce & Painel do Lojista (CMS)

Aplicação web completa, moderna, responsiva (mobile-first) e de alta conversão desenvolvida para a loja física **Happy Kids Moda Infantil**.

- **Endereço:** Rua 09, nº 865 - Centro, Santa Fé do Sul - SP
- **WhatsApp / Atendimento:** (17) 99773-2964
- **Grade de Tamanhos:** Do **RN ao 18** (`RN, P, M, G, 1, 2, 3, 4, 6, 8, 10, 12, 14, 16, 18`)

---

## 🚀 Como Executar o Projeto

Não é necessário instalar dependências externas. Basta:
1. Dar um duplo clique no arquivo **[`index.html`](./index.html)** ou no atalho **[`Abrir_Happy_Kids.bat`](./Abrir_Happy_Kids.bat)** para abrir diretamente no seu navegador (Chrome, Edge, Safari, Firefox).

---

## 📁 Estrutura de Arquivos

```text
happy-kids-ecommerce/
├── index.html             # Interface principal (Home, Catálogo, Produto, Sobre, Contato, CMS Lojista)
├── Abrir_Happy_Kids.bat   # Atalho rápido para abrir a loja no navegador no Windows
├── assets/
│   └── logo.png           # Logotipo oficial da Happy Kids Moda Infantil
├── css/
│   └── styles.css         # Identidade visual, animações, lupa de zoom e estilização mobile-first
└── js/
    ├── data.js            # Configurações da loja, grade RN-18 e catálogo inicial completo
    └── app.js             # Motor de filtros, carrinho, integração WhatsApp e CMS com LocalStorage
```
